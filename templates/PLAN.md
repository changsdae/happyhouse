## 라운드별 체크리스트

아직 없음. 라운드마다 다음 항목을 짧게 채우고 WORK.md의 상세 항목에 연결합니다.

- 구현 과제와 사용자에게 보이는 결과
- 입력 → 처리 → 출력 / 선행 라운드와 연결점
- 완료조건 / 검증 방법 / 마지막 통합 시 확인할 것
- 사람이 답할 질문과 결정 / 해당 WORK.md 대화 번호

## 계획 대화와 변경

라운드 배정 전 대화는 `계획-01`부터 기록합니다. 요약, 선택 이유, 미확정 사항, 승인 범위와 근거를 남깁니다. 세부 라운드 대화는 WORK.md에 기록합니다.
