# 전체 계획

> 평소 이 문서와 현재 라운드 WORK를 나란히 봅니다. 주담당이 저장하며, 자동 상태 관리나 실시간 시계는 없습니다.

## 지금 확인할 것

- 현재 단계 / 라운드: 문제 이해 전 / 미정
- 사람이 답할 것: 아직 없음
- 다음 행동: 제공된 문제와 지침 읽기
- 승인자: 미지정 · 계획 기준: 초안
- 마지막 갱신 시각: 미기록
- 실제 시험 잔여 시간 / 확인 근거: 미확인

## 전체 진행표

| 라운드 | 구현 과제 | 난이도 / 배정 | 목표 종료 잔여 | 진행 / 검증 | 바로가기 |
|---|---|---|---|---|---|

아직 라운드가 없습니다. 목표가 정해지면 한 행씩 추가합니다. 과제는 한 문장으로, 완료조건·선행·코드 위치는 아래 체크리스트와 WORK에 둡니다. 바로가기는 WORK와 CHECK 링크입니다.
검사할 때의 열 수와 라운드 ID는 유지합니다. 완료 직전 상태는 `검증 중 / 통과`, 최종 반영 후에는 `완료 / 통과`입니다.
관련 코드·요구가 바뀌면 해당 라운드를 `수정 중 / 재검증 필요` 등으로 바꾸고 WORK의 변경 항목으로 연결합니다.
검증담당의 판정·기록 점검과 검사 프로그램 통과 후에만 완료로 바꿉니다. 상태 변경 후 검사도 다시 실행합니다.
현재 라운드 검사 시 이미 완료된 라운드도 검사하므로 이전 통과를 무심코 유지하지 않습니다.

- 전체 제한시간: 실제 안내 확인 전
- 초기 계획 / 라운드 합계 / 최종 점검·복습·제출: 구체화 후 배정
- 배정 합계 확인: 미확인

목표 종료 잔여는 HH:MM:SS로 적습니다. 예: 전체180분 중 계획20분+첫 라운드35분 경과 → **02:05:00**. 실제 플랫폼 시계를 우선합니다.

## 라운드별 체크리스트

라운드가 정해지면 아래 내용을 각 라운드 제목 아래 짧게 적고 WORK로 연결합니다.

- [ ] 구현 목표·관찰 가능한 완료조건 구체화
- [ ] 선행 라운드와 입력→출력 연결 확인
- [ ] 검증 유형·위험과 CHECK 위치 확인
- 사람이 답할 것 / WORK 대화 번호:
- 이해 확인: 아직 확인하지 않음 — 기능 완료와 별개

## 계획 대화·변경

라운드 배정 전 대화는 계획-01부터 기록합니다. 요약·선택 이유·미확정·승인 범위와 근거를 남깁니다. 의미 있는 계획 변경은 개정·이유·영향 라운드·재검토 여부를 누적하고 이전 결정을 보존합니다.
