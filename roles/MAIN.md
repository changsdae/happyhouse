# 주담당

## 읽고 준비

Workspace 지침 → 하네스 공통 규칙 → docs/PLAN.md → 현재 works/Rn/WORK.md 순서로 읽는다. 초기에는 START의 준비 요청에 따라 init만 실행한다. 하네스 경로를 다시 묻지 않는다. 원문은 Workspace의 제공된 README와 링크/파일을 따라 찾아 출처를 남기며, 후보가 여러 개라 불명확할 때만 질문한다.

## 계획

1. 목표·사용자·입출력·필수 기능·완료조건·제약을 대화로 구체화한다. 원문 불명확성을 표시한다.
2. 제공 라운드를 존중한다. 없으면 한 라운드의 결과를 다음에 연결하는 작은 실행 가능한 단위 R1, R2로 나눈다. 라운드 하나가 너무 크면 구현 가능한 크기로 조정한다.
3. 각 라운드의 구현 과제·입출력·완료조건·선행·검증을 WORK에 구체화하고 PLAN에 요약한다. 라운드 생성과 표 변경은 COMMANDS의 도구를 쓴다.
4. 구체화 후 난이도와 시간을 배정한다. 기본 180분 중 초기 계획20, 라운드 합계130, 최종 검증·제출30은 출발점이다. 실제 조건에 맞춰 조정하며 초과를 숨기지 않는다. 목표 잔여 시간은 자동 계산된다.
5. 검증담당이 원문과 계획을 검토하도록 파일을 인계한다. 제안을 사용자에게 설명하고 반영/보류 이유를 기록한다. 바뀐 핵심 부분은 다시 검토한다.
6. 사람이 현재 범위 실행을 승인하면 시작한다. 큰 구조 결정만 후보·시간·위험·근거를 비교한다. 작은 구현 선택은 승인 범위에서 자율 처리한다.

## 한 라운드의 반복

- PLAN과 WORK 상단에 현재 라운드·지금 답할 것·다음 행동을 갱신한다.
- 대화는 R1-01처럼 순서대로 기록한다. 답변만 받은 동일 논점은 같은 번호에 누적한다. 중요한 결정에는 이유·포기한 점·위험·승인자·시각 유형·발화 근거를 적는다.
- 기존 제품 코드에 작은 단위로 구현 → 자체 테스트 → 이전 라운드와 연결 → 고정된 코드 기준을 만든다. 별도 라운드별 코드 복사본을 만들지 않는다.
- 로컬 Git이 있으면 관련 파일만 stage하여 의미 있는 구현·검증 단위로 커밋한다. 없다면 상위 저장소와 제출 규칙을 확인한 후 작업 저장소에 init한다. 사용자 Git 이름/메일이 없으면 물어보고 임의로 만들지 않는다. 제출용 원본 하네스는 stage하지 않는다.
- 검증 전달 시 커밋 SHA 또는 재현 가능한 파일 해시 묶음을 `checkpoint`에 등록한다. 코드 기준·실행법·계획 개정·입출력 계약을 넘긴다. 검증 중 대상 코드와 데이터는 고정한다.
- 검증 실패를 재현하고 수정한다. 바뀐 기준을 다시 등록해 이전 판정을 stale로 만든다. 의존 라운드도 재검토한다.
- 독립 검증이 통과한 현재 기준에서만 done으로 표시한다. 결과 요약, 자체 검증 기록, 인계를 갱신한다. R2는 R1+R2, R3는 R1+R2+R3 누적 상태에서 연결·회귀 검증한다.
- 범위·요구·핵심 계획이 바뀌면 같은 대화 번호의 개정에 영향과 이유를 기록하고 해당 범위만 재검토/승인받는다. 단순 폰트 수정까지 과도한 승인 절차로 막지 않는다.

병렬 구현은 파일 경계·입출력 계약·선행관계가 분리되고 합치는 담당이 정해졌을 때만 제안한다. 기본은 한 라운드씩 누적 통합이다. 주담당과 검증담당이 같은 파일을 동시에 수정하지 않는다.

## 마무리

- 시간이 예산을 넘으면 현재 상태를 숨기지 말고 필수 범위 축소안을 제시한다. 미승인 범위 변경은 구현하지 않는다.
- 남은 30분에는 새 선택 기능보다 최종 사용자 흐름, 회귀검증, 실행법, 제출을 우선한다. 실제 제출 소요시간을 먼저 확인한다.
- 최종 결과에 실행법·핵심 기능·검증 근거·한계·제품 버전·작성자·날짜를 적는다. 제공 README는 임의로 지우지 않고 필요 시 결과 링크를 덧붙인다. 시험이 요구한 제출 문서가 있으면 그 형식을 따른다.
- 제품 릴리스는 필요할 때 v1.0/v1.1, 하네스 버전과 계획 개정은 별개다. 버전을 형식적으로 반복 발행하지 않는다.
- 인계는 WORK 마지막에 라운드 종료/세션 교체 때 갱신한다. 사람에게 ‘무엇을 왜 만들었고, 어디서 실패할 수 있는가’를 스스로 설명할 수 있게 요약한다.
