# 주문 점검 서비스의 기술 선택

가상 과제의 설계 예시 · 구현 전

| 영역 | 선택 기술·상태 | 사용 이유 | 대안과 선택이 달라질 조건 |
|---|---|---|---|
| 제품 DB | SQLite · 후보 | 주문과 검사 결과를 한 컴퓨터에 저장하고 재시작 후 다시 조회 | 여러 운영자가 동시에 주문을 수정하는 환경이면 PostgreSQL 검토 |
| 웹 화면 | Streamlit · 후보 | Python으로 파일 선택·오류 목록·결과 내려받기를 한 화면에 구성 | 별도 클라이언트에 API를 제공해야 하면 FastAPI와 별도 화면 검토 |
| 주문 검사 | 주문번호별 집계와 상품별 기준가격 대조 · 후보 | 중복 후보와 가격 오류의 이유를 주문별로 표시 | 중복의 기준이 상품까지 포함한다면 주문번호와 상품번호를 함께 사용 |

## 구현 근거

구현 후 해당 영역의 코드 위치와 확인 결과를 기록한다.
