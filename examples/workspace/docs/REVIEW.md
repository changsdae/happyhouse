# 이해와 복습

*화면 검토용 가상 예시 · 실제 구현 설명 아님*

**지금 볼 것:** 검증과 적용을 구분하는 이유.

## R1 · 데이터 적용

- **검증:** 새 파일이 조건을 지키는지 확인한다.
- **적용:** 검증한 데이터를 현재 데이터로 바꾼다.
- **분리 이유:** 오류가 있는 새 파일 때문에 기존 작업을 잃지 않도록 한다.
- **실패 조건:** 검증 실패 전에 기존 데이터를 지우는 경우.
